# Week 4 Assignment — Bible Study Chatbot

Foundations of AI course (M.S. in Applied AI). This repository holds the deliverables for the Week 4 assignment: building the instructions for a Bible study chatbot and deploying it on BoodleBox.

## Live Bot

[Bible Doctor on BoodleBox](https://box.boodle.ai/a/@BibleDoctor)

A respectful Bible study companion (2011 NIV) that helps users explore Scripture, understand what it means, and discover how it connects — for curious minds of every age, from kids to elders.

## Contents

- `CLAUDE.md` — standing context profile that tells Claude how to work on this project (background, communication preferences, and the goals of this assignment).
- `boodlebox-chatbot-instructions.md` — the full system instructions used to configure the "Bible Doctor" bot in BoodleBox (role, audience, tone, scope, and guardrails).

## Branch

This work lives on the `week4-assignment` branch, not `main`, per the assignment's submission requirements.
